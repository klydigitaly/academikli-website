AcademiKli — עמודי שירות

1. העתיקו את 10 קובצי ה-HTML ואת service-pages.css לתיקיית השורש של הפרויקט, לצד index.html.
2. אין צורך להחליף או לשנות את index.html כדי להפעיל את העמודים.
3. פתחו literature-review.html דרך Live Server ובדקו.
4. כדי לקשר מעמוד הבית, הוסיפו קישורים מהקובץ HOME_LINKS.txt לכרטיסי השירותים המתאימים.
5. לפני פרסום בדקו את מספר WhatsApp, את תוכן השירותים ואת הלוגואים (הם בנויים כטקסט מעוצב בהתאם למיתוג באתר ולא כתמונות).
6. עדכנו את sitemap.xml לכלול את כתובות העמודים החדשים.
